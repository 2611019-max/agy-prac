# AI出品アシスト機能 仕様・設計書

## 1. 概要
MEETORY（ミートリー）の独自機能である「AI出品アシスト」は、出品者が商品写真を撮影・アップロードするだけで、商品の状態判定、相場推定、おすすめ出品価格、タイトル、カテゴリ、説明文を自動生成し、出品の手間と不安を解消する機能です（企画書 P.8, P.9, P.10 参照）。

---

## 2. 解決するターゲット課題

| 出品者の課題 (P.7) | AI出品アシストによる解決 (P.8) |
| :--- | :--- |
| **相場の価格設定がわからない** | 画像認識により商品・モデルを特定し、適正な相場帯と推奨価格を自動提案 |
| **出品・取引が面倒** | 商品名・カテゴリ・状態・説明文・ハッシュタグを自動生成し、フォームへ自動反映 |
| **商品の状態や価格がわかりにくい** | 画像から傷や使用感を客観的にチェックし、適切な状態ランクを判定 |

---

## 3. 入出力仕様 (I/O)

### 入力 (Input)
- `image`: 商品写真（JPEG, PNG, WebP等）
- `user_condition`（必須/推奨）: 出品者が記入した商品の状態・補足メモ（例: 「半年ほど使用、動作確認済み。背面に薄い擦り傷あり。箱・付属品完備」等）

## 4. 技術連携方式（開発環境 P.13 準拠）

企画書 P.13 に記載されている技術環境（PHP, SQL, JavaScript, HTML, CSS, Google Gemini API）に基づく構成案:

### 構成案: PHP / JavaScript + Google Gemini API 直接連携
- **フロントエンド (HTML/CSS/JavaScript)**:
  - スライド P.9 の画面推移に基づき、写真撮影・アップロードUIを構築
  - 写真選択時にプレビューとともに「商品の状態・補足メモ」入力欄（クイック入力チップ付き）を表示
  - ユーザーが状態を入力した上で「AIで分析・出品情報を生成する」ボタンをクリック
  - アップロード時に「AIが分析中...」アニメーションを表示
  - 分析完了後、画像と状態メモを加味した商品名・カテゴリ・状態・相場・価格・説明文をフォームに自動入力
- **バックエンド (PHP)**:
  - クライアントから受け取った画像ファイルと出品者の状態メモを Google Gemini REST API（`generateContent`）へリクエスト
  - Gemini API から返却された構造化 JSON をフロントエンドへ返却
- **データベース (MySQL)**:
  - 出品確定時に商品テーブル（商品名、カテゴリ、状態、価格、説明文、画像パス等）へ保存
