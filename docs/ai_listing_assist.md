# AI出品アシスト機能 仕様・設計書

## 1. 概要
MEETORY（ミートリー）の独自機能である「AI出品アシスト」は、出品者が商品写真を撮影・アップロードするだけで、商品の状態判定、相場推定、おすすめ出品価格、タイトル、カテゴリ、説明文を自動生成し、出品の手間と不安を解消する機能です。

---

## 2. 課題と解決策

| 出品者の課題 | AI出品アシストによる解決 |
| :--- | :--- |
| **相場の価格設定がわからない** | 画像認識により商品・モデルを特定し、適正な相場帯と推奨価格を自動提案 |
| **出品・入力が面倒** | 商品名・カテゴリ・状態・説明文・ハッシュタグを1クリックで自動入力 |
| **商品の状態表記に自信がない** | AIが傷や使用感を客観的にチェックし、適切なコンディションランクを判定 |

---

## 3. 入出力仕様 (I/O)

### 入力 (Input)
- `image`: 商品写真（JPEG, PNG, WebP等、1枚〜複数枚）
- `hint_text` (任意): 出品者が入力した簡単なメモ（例: 「PS5のコントローラー、半年使用」等）

## 4. アーキテクチャ構成案

### 方式A: Python API サーバー構成（企画書スライド43に準拠）
- **構成**:
  - フロントエンド (HTML/JS) または バックエンド (PHP)
  - ───(HTTP POST)───▶
  - Python (FastAPI / Flask) + Google Gemini API (`google-genai` SDK)
- **特徴**:
  - AI機能担当（山﨑さん）が独立して開発・テスト可能
  - Gemini の最新モデル・SDK機能をフル活用しやすい

### 方式B: PHP直接 cURL 連携構成
- **構成**:
  - PHPバックエンドから直接 Gemini REST API (`https://generativelanguage.googleapis.com/v1beta/models/...`) を呼び出し
- **特徴**:
  - MAMPサーバー1台で完結、常駐Pythonプロセス不要

## 5. Gemini API プロンプト設計方針

```text
あなたはフリマアプリ「MEETORY」のAI出品アシスタントです。
提供された商品画像を詳細に観察し、出品に必要となる情報をJSONフォーマットのみで出力してください。

分析項目:
1. 商品の特定（メーカー、製品名、型番、色など）
2. 外観の状態判定（新品/未使用、目立った傷や汚れなし、やや傷や汚れあり 等）
3. 適正な市場相場価格の推定（min, max, recommended）
4. 購入者に好印象を与える親切な商品説明文の生成
5. 検索ヒットしやすい関連タグの抽出
```
