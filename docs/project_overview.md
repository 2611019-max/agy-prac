## 2. サービス概要・開発背景

### 概要
ユーザー間で不要になった商品を出品・購入できるフリマ/ECプラットフォーム。
運営側が決済・取引を仲介することで、個人間取引でのトラブルや不安を低減し、安心・スムーズな売買を実現する。

### 開発の背景
1. **「まだ使えるのに捨てるのはもったいない」**: 不要な物を必要とする人へつなげたい
2. **支払い方法や価格設定の不便さを解決したい**: 適正価格がわからない、出品手続きが面倒
3. **安心してスムーズにできる取引を実現したい**: 信頼できる相手とトラブルなく取引したい
4. **不要な物の新たな価値と「出会い」を生み出したい**: モノと人をつなぐ体験を提供

## 3. ターゲットペルソナ

### 出品者側ペルソナ
- **属性**: 20代前半・男性・大学生（一人暮らしまたは実家、趣味: ゲーム・PC関連）
- **行動・特徴**: PCやゲーム関連商品をよく購入。使わなくなった機器が家に眠っている。
- **課題**: 捨てるのはもったいないが相場がわからない、出品が面倒、個人間取引が不安。
- **利用目的**: 使わなくなった物を捨てずに、必要としている人に届けたい。

### 購入者側ペルソナ
- **属性**: 30代前半・女性・会社員（事務職など、趣味: カフェ巡り・ショッピング等）
- **行動・特徴**: できるだけ安く購入したい、状態が良ければ中古品で十分。
- **課題**: 欲しい商品を探すのに時間がかかる、商品の状態や価格がわかりにくい、取引が不安。
- **利用目的**: 新品よりも安く、状態の良い商品を手軽かつ安心して手に入れたい。

## 4. MEETORY の5大独自特徴

1. **AI出品アシスト** (Gemini API)
   - 商品写真から状態分析、相場分析を行い、おすすめ出品価格・商品説明文・カテゴリを自動提案。
2. **SNS的なフォロー / タイムライン機能**
   - お気に入りのユーザーをフォローし、タイムラインで最新の投稿や出品をチェック。
3. **出品時の対応評価表示 / 評価の取引後アクション化**
   - 取引相手の対応評価を可視化。取引後の評価を次回のおすすめや信頼スコアに活用。
4. **カテゴリ超えのレコメンド**
   - ユーザーの興味関心に基づき、関連する他カテゴリの商品を提案（例: ゲーム機購入者にPC周辺機器）。
5. **カテゴリ別の簡易補償**
   - 取引商品のカテゴリに応じた安心の補償プランを用意し、トラブル時の不安を解消。

## 7. マネタイズ計画

1. **基本収益**: 出品者からの販売手数料 **5%**（購入者は基本無料）
   - 例: 3,000円の商品 → 手数料 150円
   - 例: 10,000円の商品 → 手数料 500円
2. **将来的な追加収益**:
   - プレミアム会員費（月額300〜500円）
   - 追加補償有料プラン
   - 企業広告・PR掲載費
3. **目標成長推移**:
   - 1年目: ユーザー数 1万人
   - 3年目: ユーザー数 10万人 / 企業クライアント 10社
   - 5年目: ユーザー数 50万人 / 企業クライアント 50社
   - 将来: ユーザー数 100万人以上 / 企業クライアント 100社以上
