## 2. サービス概要・開発背景（P.3〜P.4）

### 作品概要（P.3）
- ユーザー同士が不要になった商品を出品・購入できるECプラットフォーム。
- 運営側が決済や取引を仲介することで、個人間取引におけるトラブルや不安を減らし、安心して商品の売買ができる環境を提供。
- 不要になった物を必要とする人へつなげることで、商品の新たな価値やユーザー同士の「出会い」を生み出すことが目的。

### 開発の背景（P.4）
- 「まだ使えるのに捨てるのはもったいない」そんな想いから、meetory は生まれました。
  1. **まだ使えるのに捨てるのはもったいない**: 不要な物を必要な人へつなげたい。
  2. **支払い方法や価格設定の不便さを解決したい**: もっと簡単に、自分に合った方法で取引したい。
  3. **安心してスムーズにできる取引を実現したい**: 信頼できる相手と、安心して取引できる環境をつくりたい。
  4. **不要な物の新たな価値と「出会い」を生み出したい**: モノと人をつなぎ、新しい価値や出会いを生み出したい。

## 3. ターゲットペルソナ（P.5〜P.6）

### 出品者側ペルソナ（P.5）
- **20代男性・大学生【出品者】**
  - 年齢: 20代前半
  - 職業: 大学生
  - 居住地: 一人暮らし（または実家）
  - 趣味: ゲーム・PC関連
- **声**: 「使わなくなったものを、必要としている人に届けたい。」
- **特徴・行動**: ゲームが好き、PC/ゲーム関連商品をよく購入、不要になった機器を持っている、捨てるのはもったいない、必要な人に売りたい、安心して取引したい
- **悩み・課題**: どうするか悩んでいる、捨てるのはもったいない、出品方法がわからない、トラブルなく取引したい
- **利用理由**: 使わなくなった物を捨てずに、必要としている人に届けたい。

### 購入者側ペルソナ（P.6）
- **30代女性・社会人【購入者】**
  - 年齢: 30代前半
  - 職業: 会社員（事務職など）
  - 居住地: 一人暮らし（または実家）
  - 趣味: カフェ巡り・ショッピング・映画鑑賞
- **声**: 「欲しいものを、できるだけお得に手に入れたい。」
- **特徴・行動**: 安く購入したい、中古でも状態が良ければ気にしない、手軽に探したい、安心して取引したい
- **悩み・課題**: 安く買いたい、中古品の状態が良いか不安、商品を探すのに時間がかかる、トラブルなく安全に取引したい
- **利用理由**: 新品よりも安く、状態の良い商品を購入したい。

## 4. ターゲットが抱える課題（P.7）

### 出品者の課題
1. 不要なものを捨てるのはもったいない
2. 相場の価格設定がわからない
3. 出品・取引が面倒
4. 個人間の取引が不安

### 購入者の課題
1. ほしい商品を探すのに時間がかかる
2. 商品の状態や価格がわかりにくい
3. 個人間の取引が不安

## 5. 作品の特徴（P.8）
5つの独自機能で、もっと安心・もっと便利に、もっと楽しく。

1. **AI出品アシスト**: 商品の写真から、状態の分析や相場の価格を調べて、おすすめの価格を提案。
2. **SNS的なフォロー/タイムライン機能**: 気になるユーザーをフォローしたり、タイムラインで最新の投稿や商品をチェック。
3. **出品時の対応評価表示 / 評価の取引後アクション化**: 取引相手の対応評価を確認でき、取引後はお互いに評価を行うことで信頼できる取引を実現。
4. **カテゴリ超えのレコメンド**: 興味や行動から関連する商品をおすすめし、欲しかったものを見つけやすくする（例: ゲーム → PC周辺機器）。
5. **カテゴリ別の簡易補償**: カテゴリごとに安心の補償を用意し、万が一のトラブルにも対応。

## 6. 画面推移（P.9）
「売る」「買う」「つながる」すべてがひとつのアプリで完結。

- **ログイン・会員登録 / ホーム画面 / マイページ**
- **購入の流れ**:
  商品を探す → 商品一覧 → 商品詳細 → 購入手続き → 支払い → 取引画面 → 商品受取 → 評価 → おすすめ商品 → 新しい商品との出会い
- **出品の流れ**:
  出品 → 商品写真を撮影 → **AI出品アシスト** → 出品内容の確認 → 出品完了 → 購入される → 取引画面 → 評価
- **SNS・交流の流れ**:
  ホーム → SNS・タイムライン → フォローしているユーザーの投稿 → 気になる商品を発見 → 商品詳細

## 8. 競合比較（P.11）

| サービス | 強み | 弱み | 重視している点 |
| :--- | :--- | :--- | :--- |
| **ヤフオク** | ・価格が競り上がる（オークション）<br>・高額・マニア品に強い<br>・売り方を選べる（即決/競り） | ・現金化に時間がかかる<br>・安値で買われるリスク<br>・仕組み・画面がやや複雑 | 高値・マニア向けの取引機会 |

| **楽天ラクマ** | ・楽天ポイントが使える・貯まる<br>・手数料が安い（3.5%〜）<br>・安心・安全な取引 | ・ユーザー数がメルカリより少ない<br>・出品制限がある場合がある<br>・使い勝手がややシンプル | 信頼性・安心感・楽天ポイント活用 |

## 9. マネタイズ（P.12）

### 誰がお金を払う？
- **出品者（メイン）**: 商品が売れた際に販売手数料を徴収（販売手数料 5%）
- **購入者（サブ）**: 基本無料で利用可能。将来的に有料プランを提供（プレミアム会員・追加補償）
- **企業（将来）**: 広告・PR掲載などで企業から収益を獲得

### 価格案
- **販売手数料**: **5%**（3,000円の商品 → 150円、10,000円の商品 → 500円）
- **今後の収益プラン**:
  - プレミアム会員: 月額300〜500円
  - 追加補償: 有料プラン
  - 企業広告・PR掲載広告費

### ユーザー・企業目標
- **ユーザー数（登録者）**: 1年目 1万人 → 3年目 10万人 → 5年目 50万人 → 将来 100万人以上
- **企業数（クライアント）**: 3年目 10社 → 5年目 50社 → 将来 100社以上
