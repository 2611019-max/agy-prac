## 主な特徴
1. **AI出品アシスト**: 写真から商品特定・状態判定・相場推定・おすすめ価格・説明文を自動生成
2. **SNS的なフォロー/タイムライン機能**: 気になる出品者をフォローしてタイムラインで発見
3. **出品時の対応評価表示 / 評価の取引後アクション化**: 安心・安全な取引体験
4. **カテゴリ超えのレコメンド**: ユーザーの関心に合わせた横断提案
5. **カテゴリ別の簡易補償**: 万が一のトラブル時にも安心な補償制度
